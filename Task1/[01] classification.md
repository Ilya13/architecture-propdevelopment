# Классификация данных по стандартам ISO/IEC 27001 и 27002

## 1. Данные об объектах недвижимости

- **Описание**: Описание квартир, фотографии, цены, доступность.
- **Классификация**: Публичные данные.
- **Обоснование**: Эти данные доступны для публичного просмотра на сайте, но внутренняя система управления ими требует защиты от несанкционированных изменений.

## 2. Персональные данные клиентов

- **Описание**: Ф. И. О., контактные данные — телефон и электронная почта, данные клиента, использующиеся при проведении онлайн-сделки.
- **Классификация**: Конфиденциальные данные.
- **Обоснование**: Утечка этих данных может привести к серьёзным последствиям, включая мошенничество, а также нарушения законодательства о защите персональных данных.

## 3. Финансовые данные

- **Описание**: Информация о продажах, данные о транзакциях, реквизиты платёжных карт.
- **Классификация**: Конфиденциальные данные.
- **Обоснование**: Утечка финансовых данных может привести к значительным убыткам и нарушениям законодательства, связанным с защитой данных платёжных карт.

## 4. Системные и технические данные
- **Описание**: Журналы логирования IT-систем, данные о конфигурациях оборудования, информация о сетевой инфраструктуре.
- **Классификация**: Внутренние данные
- **Обоснование**: Эти данные могут использоваться злоумышленниками для проведения атак на инфраструктуру компании.

## 5. Секретные ключи
- **Описание**: Ключи шифрования, учетные данные доступа к сервисам.
- **Классификация**: Секретные данные
- **Обоснование**: Эти данные могут использоваться злоумышленниками для получения доступа к данным компании.

# Оценка рисков

| Угроза | Описание | Оценка риска |
| -------------- | ------------------ | ------------------------- |
| Искажение публичные данные | Несанкционированное изменение цен или характеристик может ввести в заблуждение клиентов и нанести ущерб репутации | Значительный |
| Некачественные публичные данные | Устаревшие или не верные данные может ввести в заблуждение клиентов и нанести ущерб репутации | Незначительный |
| Утечка персональных данных | Приведёт к штрафам и потере доверия клиентов | **Критический** |
| Утечка финансовой информации | Кража финансовой информации может привести к финансовым потерям компании и клиентов | **Критический** |
| Утечка системных данных | Несанкционированный доступ к логам может скрыть следы инцидентов безопасности | Значительный |
| Утечка секретных данных | Кража секретных данных может привести раскрытию критической для компании информации | **Критический** |
